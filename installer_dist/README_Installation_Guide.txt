Welcome to DentaLink Patient Management Desktop Application.
This folder contains the complete standalone Windows Installer package.

------------------------------------------------------------------------
📌 INSTALLATION INSTRUCTIONS
------------------------------------------------------------------------

1. RUN THE INSTALLER:
   - Double-click "DentaLinkSetup.exe".
   - Follow the modern setup wizard to install DentaLink to your PC.
   - (Optional) Check "Create a Desktop Icon" for quick access.

2. LAUNCH & FIRST-TIME CLINIC SETUP:
   - Launch DentaLink from your Desktop shortcut or Start Menu.
   - On first run, DentaLink automatically creates a clean, empty database.
   - The "First Launch Setup Wizard" will appear:
     a. Enter your Clinic Name.
     b. Create your Admin Doctor Account (Doctor Name, Username & Password).
     c. Set your 2-Factor Password Recovery Questions.

3. SAVE YOUR EMERGENCY RECOVERY KEY:
   - During setup, a 16-character Universal Recovery Key (e.g. XXXX-XXXX-XXXX-XXXX)
     will be generated.
   - Click "Copy to Clipboard" or "Save to File" and store it in a safe place.
   - This key is used for emergency password recovery without data loss.

------------------------------------------------------------------------
🛡️ SYSTEM REQUIREMENTS
------------------------------------------------------------------------

- Operating System: Windows 10 or Windows 11 (64-bit)
- Legacy OS Support (Windows 7 SP1):
  If installing on Windows 7, ensure the following are installed:
  1. Windows 7 Service Pack 1 (SP1)
  2. Microsoft Visual C++ 2015-2022 Redistributable (x64)
  3. Graphics Driver with DirectX 11 / OpenGL support

------------------------------------------------------------------------
🔒 DATABASE & BACKUP ADVICE
------------------------------------------------------------------------

- Application Location: AppData\Local\DentaLink
- Database Location: AppData\Local\DentaLink\dental_clinic.db
- BACKUP: Periodically back up "dental_clinic.db" to preserve your patient
  records, clinical histories, and X-ray images.
